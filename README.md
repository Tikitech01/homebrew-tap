# Homebrew tap for Scientific Calculator

A free, offline scientific calculator for engineering students, by Sopè Technology.

```
brew install --cask tikitech01/tap/scientific-calculator
```

Updates: `brew upgrade --cask scientific-calculator`.

The app is not notarised by Apple yet. If macOS says it cannot be opened, open
System Settings ▸ Privacy & Security and click "Open Anyway".

Source and downloads for Windows and Linux: https://github.com/Tikitech01/scientific-calculator
